# (1) 재료 모으기
- 연구의 하루가 어떻게 구성되는지 쪼개기
	- 업무 목록표 기반
		- 업무, 빈도, 입력 자료, 결과물, 어려운점
		=> 어려운 점 컬럼이 가장 중요 => 에이전트가 해결할 지점
	- 기준 세우기
		- 동사로 적기 => 동사는 그 문장 그대로 요청이 됨
		- 30분 단위로 쪼개기 => 논문 쓰기(= 프로젝트), Related Work(= 문단 수정) ==> 이게 업무임
		- 귀찮은 일에 별표 => 반복의 신호(=> 자동화의 신호)
	- 컬럼 하나하나 => 에이전트 설계도
		- 업무(동사) -> 에이전트에게 시킬 문장
		- 빈도 -> 자동화 우선순위 - 자주 하는 일부터
		- 입력 자료 -> LLM Wiki에 쌓을 재료
		- 결과물 -> Skill의 출력 형식
		- 어려운점 -> CLAUDE.md에 들어갈 검증 규칙의 재료
	- 논문 분석시 정리 목록(최소한)
		- 1. 연구 목적
			- 무엇을 해결하려고 했는가?
		- 2. 연구 문제
			- 어떤 문제가 있다고 보는가?
		- 3. 연구 대상
			- 어떤 시스템/환경을 대상으로 하는가?
		- 4. 연구 방법
			- 어떻게 해결했는가?
		- 5. 핵심 결과
			- 무엇을 발견했는가?
		- 6. 기존 연구와 차이
			- 기존 연구보다 뭐가 다른가
		- 7. 한계
			- 스스로 인정한 문제는?
		- 8. 내가 가져갈 것
			- 내 연구에 어떤 도움이 되는가?
		- 9. 내 연구와의 관계
			- 참고 / 비교 / 반박 / 확장 중 무엇인가?
	- 연구 로그 정리
		- 오늘 한 일
		- 오늘 알게 된 것
		- 오늘 생긴 질문
		- 내일 할 일
		- 막힌 부분
