# (1) 재료 모으기
- 연구의 하루가 어떻게 구성되는지 쪼개기
	- 업무 목록표 기반
		- 업무, 빈도, 입력 자료, 결과물, 어려운점
		=> 어려운 점 컬럼이 가장 중요 => 에이전트가 해결할 지점
	- 기준 세우기
		- 동사로 적기 => 동사는 그 문장 그대로 요청이 됨
		- 30분 단위로 쪼개기 => 논문 쓰기(= 프로젝트), Related Work(= 문단 수정) ==> 이게 업무임
		- 귀찮은 일에 별표 => 반복의 신호(=> 자동화의 신호)
	- 컬럼 하나하나 => 에이전트 설계도
		- 업무(동사) -> 에이전트에게 시킬 문장
		- 빈도 -> 자동화 우선순위 -
