# 분석 노트 — RS-485 통신보안에 관한 실증적 연구

- 서지: 홍봉조(유한대), 김춘경(한국도로공사), 최은희(인천재능대), 이남용(숭실대), 한국IT정책경영학회 논문지 Vol.10 No.4, pp.917-, 2018.08 (논문번호 18-10-04-09)
- 원문: `papers/RS-485 통신보안에 관한 실증적 연구.pdf`
- 표기: `[논문]` = 원문에 직접 적힌 내용 / `[추론]` = 내 해석

> ⚠️ **취약점 분석 논문이 아니라 암호화 성능 측정 논문이다.** R1의 직접 근거로 쓸 수 없고, "시리얼은 기본적으로 암호화되지 않으며 이를 적용하면 비용이 발생한다"는 **보조 근거**로만 쓴다.

## 1. 연구 목적
[논문] ARM embedded 및 FreeRTOS 환경에서 미국 표준 AES와 국내 표준 ARIA의 RS-485 통신 암호화 성능을 측정·비교하는 것.

## 2. 연구 문제
[논문] "RS-485 통신메세지가 암호화가 되지 않았다면 외부로부터 무단 접속되는 경우, 해킹의 피해로 이어질 우려가 있다. 따라서 RS-485의 보안성을 높이기 위해서는 통신데이터를 암호화하여야 한다."
[논문] "RS-485방식에 암호화가 사용되지 않는다면, 엘리베이터 등 산업기기의 데이터 해독 취약성으로 인해 해킹 우려된다."

## 3. 연구 대상
[논문] RS-485 반이중(half duplex) 시리얼 통신. 산업기기(엘리베이터 등)에서 널리 사용.

[논문 — 표 1 시리얼 통신 비교]

| 규격 | RS-232C | RS-422 | RS-485 |
|---|---|---|---|
| 최대 통신속도 | 20 kb/s | 10 Mb/s | 10 Mb/s |
| 최대 통달거리 | 약 15m | 약 1.2km | 약 1.2km |
| 전송방식 | 전이중 | 전이중 | **반이중** |
| 동작모드 | Single-Ended | Differential | Differential |

## 4. 연구 방법
[논문]
1. 96MHz 32비트 ARM CPU, ADuM3200(디지털 아이솔레이터), TISP3082F3(과전압 억제 IC)로 RS-485 통신회로 Testbed Module 2대 구성, TRX+/TRX- 선 상호 연결
2. FreeRTOS 환경에서 Data Link Layer와 Application Layer 구현, 4개 Task 구성
3. 18바이트 패킷을 1ms 단위로 암호화하여 TX Queue에 적재, RS-485 Driver Task가 1바이트씩 전송
4. AES·ARIA 각각 128/192/256비트로 암호화 시간, 복호화 시간, 통신속도 측정

## 5. 핵심 결과
[논문]
- **암호화 시간**: AES 128 3.3ms / 192 4.6ms / 256 4.6ms — ARIA 128 0.4ms / 192 0.43ms / 256 0.48ms
- **복호화 시간**: AES 128 3.2ms / 192 4.2ms / 256 4.2ms — ARIA 128 0.32ms / 192 0.36ms / 256 0.4ms
- 복호화 시간은 **AES가 ARIA보다 10배 이상** 소요
- **통신성능(평문 대비)**: AES128 45.1%, AES192 40.1%, AES256 35.5% / ARIA128 99.8%, ARIA192 99.4%, ARIA256 99.2%
- 평문 88,560 bitrate → AES128 39,922 bitrate

## 6. 기존 연구와 차이
[논문] 선행연구는 RS-485상의 데이터 충돌, MODBUS를 이용한 전송망 데이터 신뢰성을 다루었고, MODBUS 논문은 **평문에 대해서만** 통신성공률을 측정(500m 89%, 1km 84.2% 등). 이 논문은 **미국·한국 암호표준별로 암호화·복호화 통신성능을 분석**했다는 점에서 차이.

## 7. 한계 (저자 인정 + 관찰)
[논문 — 저자 인정] "본 논문은 **단방향 전송에 대해서만** 암복호화에 대한 통신성능을 확인하였다는 점에서 한계를 갖는[다]"

[추론 — 내 관찰]
- **공격 실험이 전혀 없다.** "암호화되지 않으면 위험하다"는 것은 서론의 전제로 서술될 뿐 실증되지 않음
- 대상이 엘리베이터 등 일반 산업기기이고 선박이 아님
- 학회 등급이 상대적으로 낮음(한국IT정책경영학회) → 핵심 논거를 여기 의존하면 안 됨

## 8. 내가 가져갈 것
1. **RS-485는 기본적으로 암호화되지 않는다**는 사실의 국내 학술 근거. 다만 이건 이 논문의 *전제*이지 *발견*이 아니므로, 인용 시 "암호화를 별도로 적용해야 한다는 전제 하에 성능을 측정한 연구"로 정확히 서술
2. **⭐ 암호화 적용의 비용**: 평문 대비 통신성능이 AES 적용 시 **35~45% 수준으로 떨어진다.** 이것이 시리얼 구간에 보안이 잘 적용되지 않는 실질적 이유를 설명 → 장지웅·김휘강(2013)의 "논의 7~8년 경과했으나 도입한 곳 없음"과 같은 방향
3. RS-232C/422/485 비교표 — 시리얼 통신 배경 서술 시 참조 (통달거리 1.2km는 선내 배선 규모에서 충분)
4. ARIA가 경량 임베디드에서 유리하다는 결과 — 2단계 방어 방법 연구 시 참조 가능

## 9. 내 연구와의 관계
**참고 (보조 근거).**
- R1의 직접 근거로 쓰면 안 됨 (공격 실증이 없음). 직접 근거는 장지웅·김휘강(2013)과 Forescout(2026)
- 이 논문의 역할은 두 가지: ① 시리얼의 기본 무암호화가 학술적으로 전제되고 있음을 보이는 것 ② **보안 적용의 비용**을 정량적으로 보여 "왜 적용되지 않는가"를 설명하는 것
- ②가 본 연구의 "이행 부담이 크면 우회된다"는 논지와 구조적으로 호응
