## 1. 패킷 수신 방법
-  패킷이 네트워크에서 컴퓨터로 들어오는 방식 => 패킷 스니핑이 동작하는 방식 이해 가능
### 1. 네트워크 인터페이스 카드(NIC)
- 기기는 NIC(Network Interface Card)를 통해 네트워크에 연결
	-> NIC는 시스템과 네트워크 간의 물리 또는 논리 링크
-  매체에서 데이터가 전달될 때 네트워크의 모든 NIC는 유선에 있는 프레임을 모두 볼 수 있음
- <커널 내부의 일반적인 패킷 흐름>
	- 프레임이 매체에 도착 -> 헤더의 목적지 주소를 확인하는 NIC 내부 메모리에 복사
	- 주소가 카드의 MAC 주소와 일치하면, DMA(Direct Memory Access)를 통해 프레임이 커널의 버퍼에 추가로 복사됨.
	- 카드는 CPU에 인터럽트를 걸어서 새로운 패킷의 가용성을 알림
	- CPU는 버퍼의 모든 패킷을 큐(Queue)로 복사하여 더 많은 수신 패킷을 위한 버퍼 공간으로 만듬
	- 프로토콜에 따라 이 큐의 데이터를 처리하기 위해 커널이 다른 Callback handler 함수를 호출
		Callback handler 함수 : 패킷을 사용자-공간 프로그램에 할당
- <무차별 모드(Promiscuous Mode)>
	- 의도하는 NIC로 가지 않는 프레임은 처리를 위해 CPU로 전달되지 않고 폐기
		-> 일반적으로는 다른 컴퓨터간 전송되는 프레임을 볼 수 없으므로, 네트워크 트래픽을 스니핑할 수 없음
	=> NIC를 무차별 모드로 전환이 필요(이땐, root와 같은 상승된 권한이 필요)
	- 이 모드가 동작시에는 NIC는 목적지 주소가 카드 자체 주소와 일치하는지 여부에 관계없이 네트워크에서 수신한 모든 프레임을 커널로 전달
		-> Snipper 프로그램이커널에 등록되면 이 모든 프레임은 결국 커널에 의해 스니퍼 프로그램으로 전달됨
- 유선 네트워크에선 무차별 모드 == 무선 네트워크 카드에선 모니터 모드
