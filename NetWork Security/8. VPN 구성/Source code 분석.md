- VPN은 가상 네트워크 인터페이스인 TUN/TAP 인터페이스가 활용
	- TUN 
		- 네트워크 스택의 OSI 3 계층(네트워크(IP) 계층)에서 동작
		- 기본적으로는 점-대-점(P2P) 네트워크 통신을 지원
		- 생성하는 동안, 플래그를 사용하여 Broadcast나 Multicast를 지원하게 구성 가능
		- 패킷을 TUN 인터페이스로 보내면 패킷이 IP 헤더를 포함하여 사용자-공간 프로그램으로 전달
		=> TUN 인터페이스를 사용하여 Layer 3 VPN을 구축가능
	- TAP
		- 이더넷 레벨 == OSI 2 계층에서 동작
		- 네트워크 어댑터와 유사하게 동작
		- 모든 Layer 3 프로토콜을 전송할 수 있으며, 점-대-점 연결에 제한되지 않음
		- 일반적인 용도 : 호스트 컴퓨터의 물리적 장치에 연결하는 여러 게스트 컴퓨터에 가상 네트워크 어댑터를 제공
		=> 이더넷 프레임과 함께 동작 가능 --> 브리지 네트워크를 만드는데에도 광범위하게 사용
