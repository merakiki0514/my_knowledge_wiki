# 1. Netfilter
- 리눅스 커널은 netfilter 후크(hook)를 사용하여 풍부한 패킷 처리와 필터링 프레임워크를 제공
- 커널 모듈을 이용하여 이 hook에 콜백 함수를 등록할 수 있음
- Netfilter는 커널 모듈이 이 hook 에서 콜백 함수를 등록했는지 확인하며, 등록된 각 모듈이 호출되며, 패킷을 자유롭게 분석하거나 조작할 수 있음
- hook의 우선 순위 : 낮은 값 -> 높은 값
## (1) Netfilter의 Hook
- NF_INET_PRE_ROUTING
	- 무차별 모드로 인한 패킷을 제외하고 모든 수신 패킷이 마주치는 hook
	- 라우팅 결정이 내려지기 전에 호출
- NF_INET_LOCAL_IN
	- 들어오는  패킷은 라우팅을 거쳐 패킷이 다른 시스템을 위한 것인지, 호스트자체를 위한 것인지 결정
	- 다른 시스템을 위한 것 => 전달 경로로 이동
	- 호스트자체를 위한 것 => NF_INET_LOCAL_IN hook를 거친 후 네트워크 스택으로 전송되어 호스트에 의해 소비
- NF_INET_FORWARD
	- 다른 호스트로 전달되는 패킷이 도달하는 hook
	- 대부분의 패킷은 라우터에서 이 hook를 통과하므로, 일반적으로 네트워크를 보호하기 위한 규칙을 설정하는 데 사용
- NF_INET_LOCAL_OUT
	- 로컬 호스트에서 생성된 패킷이 이 hook에 도달
	- 호스트에서 나가는 패킷의 첫번째 후크
- NF_INET_POST_ROUTING
	- 전달되거나 생성된 패킷이 호스트에서 나갈때 전달되는 hook
	- SNAT(Source Network Address Translation)이 구현되는 hook
## (2) Hook 함수의 반환값
- NF_ACCEPT
	- 패킷이 계속 이동
- NF_DROP
	- 패킷을 폐기하여 패킷이 네트워크 스택을 통한 이동을 계속할 수 없게 함
