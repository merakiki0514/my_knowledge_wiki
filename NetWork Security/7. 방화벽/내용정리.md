# 1. Netfilter
- 리눅스 커널은 netfilter 후크(hook)를 사용하여 풍부한 패킷 처리와 필터링 프레임워크를 제공
- 커널 모듈을 이용하여 이 hook에 콜백 함수를 등록할 수 있음
- Netfilter는 커널 모듈이 이 hook 에서 콜백 함수를 등록했는지 확인하며, 등록된 각 모듈이 호출되며, 패킷을 자유롭게 분석하거나 조작할 수 있음
## (1) Netfilter의 Hook
- NF_INET_PRE_ROUTING
	- 무차별 모드로 인한 패킷을 제외하고 모든 수신 패킷이 마주치는 hook
	- 라우팅 결정이 내려지기 전에 호출
- NF_INET_LOCAL_IN
