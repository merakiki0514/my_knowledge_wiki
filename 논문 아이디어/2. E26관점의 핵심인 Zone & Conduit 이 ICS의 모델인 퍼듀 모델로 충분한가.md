ISA/IEC 62443의 네트워크 분리 및 보안 영역 설계의 근간
## OT 영역
1. Level 0 | Physical Process(물리적 공정)
	- 주요 장비: 센서, 액추에이터, 로봇 암, 벨브, 모터
	- 역할 : 온도, 압력, 유량 등 실제 물리 현상을 측정하거나 직접 작동시키는 단계
2. Level 1 | Basic Control (기초 제어)
	- 주요 장비 : PLC, DCS 컨트롤러, RTU, SIS(안전 계장 시스템)
	- 역할 : Level 0의 센서 신호를 받아 미리 작성된 로직에 따라 액추에이터에 제어 명령을 내림 / 실시간성(Real-time response)이 극도로 중요한 구간
3. Level 2 | Area Control (공정 제어 및 모니터링)
	- 주요 장비 : HMI, 엔지니어링 워크스테이션, 알람 서버
	- 역할 : 운영자가 현장 공정 상태를 화면으로 모니터링하고 제어 파라미터를 변경하는 구역
4. Level 3 | Site Operation (생산 운영 관리)
	- 주요 장비 : MES(Manufacturing Execution System), Plant Historian(공정 데이터 저장소), OT 도메인 컨트롤러(AD)
	- 역할 : 단일 공정을 넘어 공장 전체의 생산 일정 관리, 데이터 수집, 배차, 품질 관리를 담당 / IT기술(IP 기반 네트워크, OS)이 본격적으로 접목
### iDMZ(완충 영역)
1. Level 3.5 | Industrial DMZ (산업용 DMZ)
	- 주요 장비 : 점프 호스트(Jump Host/Bastion), 데이터 다이오드, 레포트 서버, 패치
