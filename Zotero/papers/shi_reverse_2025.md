# Reverse Engineering of Private Protocols: Methods, Tools, Challenges and Future Directions

> Shi, Ke, Chen, Xingchi, He, Yuyu et al. — *2025 IEEE 10th International Conference on Data Science in Cyberspace (DSC), 2025*

## Summary

As the digital infrastructure grows, network protocols are essential for modern connectivity. However, many proprietary protocols used in IoT, ICS/SCADA, and mobile applications lack public documentation, creating “black boxes” that hinder security analysis and open hidden paths for cyberattacks. Private Protocol Reverse Engineering (PRE) addresses this by inferring protocol specifications from network traffic, binaries, or system behavior without prior knowledge.This survey reviews key PRE methods, including network traffic and program analysis, and highlights how machine learning enhances automation and accuracy. It introduces representative tools and real-world applications in IoT and ICS security and vulnerability discovery.
