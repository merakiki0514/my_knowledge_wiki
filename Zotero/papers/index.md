## 빈 상태

`references.bib`가 비어 있어 항목이 없습니다. Zotero에서 BibLaTeX으로 내보내면 자동으로 채워집니다.

## 예정 컨벤션

| 필드 | 값 |
| --- | --- |
| 파일명 | `YYYY-authorname-slug.md` (예: `2024-smith-synthetic-data.md`) |
| 프런트매터 | `type: paper`, `title`, `tags`, `timestamp` |
| Summary | 페이지 맨 위 한 문단 (Abstract 요약, 없으면 생성) |
