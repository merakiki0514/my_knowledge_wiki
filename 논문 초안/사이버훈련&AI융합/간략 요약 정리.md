	- 프레임워크 다층 계층 아키텍처(9개)
		- 1. Ship Simulation Layer - 선박-항만 간 통신 및 연계 모사
		- 2. Cyber Range Layer - P2V 가상화 네트워크 + 실제 PLC 물리 장비 연동
		- 3. Network Monitoring - Fast-Whisper/MISP 연동 IDS 
		- 4. Security Layer - SIEM 기반 이벤트 상관분석 및 비지도학습 ADS
		- 5. CERT Layer - MISP 위협 정보 공유 (해양 특화 IoC 공유)
		- 6. Recommendation Layer - VLMM 기반 차세대 위협 예측
		- 7. Training Layer - 역할 기반 학습 관리 시스템
		- 8. Risk Modeling Layer - MaCRA (해양 사이버 리스크 정량 평가)
		- 9. Econometric Layer - 물류 연쇄 중단 시 경제적 손실 정량화 산출
	- 항만 정보 자산 분류
		- CMLCA(Core Maritime Logistics Chain Assets) : 물류 프로세스를 직접 수행하는 시스템
		- SMLCA(Secondary Maritime Logistic Chain Assets) : CMLCA가 정상 작동하도록 지원하는 인프라 자산
	- 실제 인프라 구조를 바탕으로 실시간 킬체인 시뮬레이션 수행
		- 결과 -> Modbus 프로토콜을 이용해 STIP 명령으로 PLC 강제 정지
	- 가상화 IT 인프라와 실제 물리적 제어기를 결합한 하이브리드 사이버 레인지를 구축하여 침해사고 시뮬레이션 진행
