- AiCEF: an AI-assisted cyber exercise content generation framework using named entity recognition
	- 사이버 보안 훈련(CSE) 개발 프로세스의 문제에 대한 고찰
		- 자원, 전문성 소모
		- 훈련기획자(EP)의 숙련도 편차
		- 위협 데이터의 비구조성
	- CESO 온톨로지 제안, End-to-End 자동화 프레임 워크 구축, 실증적 검증
	- CESO 구조
		- STIX 2.1을 베이스
		- 정보 계층과 운용 계층의 2중 구조(SAM)로 작동
	- AiCEF 파이프라인
		- 1. 데이터 수집 -> 웹 크롤러를 통해
		- 2. MLCESO(ML 온톨로지 매핑) -> NER 훈련 및 정규표현식 및 MITRE ATT&CK 하드코딩 리스트를 결합한 하이브리드 인핸서 적용
		- 3. 성숙도 평가 알고리즘 -> 임계값 기반 DB저장
		- 4. IncGen & APT Enhancer -> 시나리오 고도화
		- 5. MLTP -> DB내의 데이터를 기반으로 SARIMA 시계열 모델 적용
		- 6. CEGen / STG (Storyline Text Generator) -> CESO 그래프 구조를 기반 자연서 생성 모델(GPT-2)에 입력하여, 기계, 인간이 읽을 수 있는 시나리오 텍스트로 변환
	- 기획자와 완전 자동화 AI를 사이버 훈련 시나리오를 작성 수행 및 평가
	- 시나리오 자동 생성하기 위한 AI 프레임워크 개발

		- Configuration Interpreter & Backend
		- Agentic Feedback Controller
	- 가설 기반 교정(Hypothesis-Driven Correction) 알고리즘 도입
		- 특정 오류 패턴에서 비수렴 상태에 빠지는 결과를 해결하기 위함
