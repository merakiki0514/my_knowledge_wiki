# IEC 62443-2-1

**Security for industrial automation and control systems — Part 2-1: Security program requirements for IACS asset owners**. Edition 2.0, 2024-08. 194쪽.

⚠️ **저작권 제약**: IEC 저작물이며 보유본에 **단일 사용자 라이선스** 워터마크가 있다.
→ **본문을 옮겨 적지 않는다. 조항 번호만 인용한다.** Wiki를 외부에 공유할 경우 이 PDF는 포함하지 않는다.

## Overview

**자산 소유자(asset owner)** 관점의 보안 프로그램 요건을 규정한다. IEC 62443 계열 중 이 파트만 보유하고 있다.

[INFERENCE] 해양 맥락에서 asset owner는 **선주·선박관리사**에 해당한다. 따라서 이 문서는 [[UR E27]](장비 공급자 관점)이나 [[UR E22]](통합자 관점)와 대상이 다르다. [확인 필요]

## Limitations

- 저작권·라이선스 제약으로 본문 인용 불가.
- 62443 계열 중 **-2-1만 보유**한다. 시스템 보안 요건(-3-3), 제품 개발(-4-1), 구성요소 요건(-4-2)이 없다.
  → 강의 노트에 나오는 SL-T/SL-A/SL-C, FR/SR 등의 용어는 **1차 근거가 없다.**
- [INFERENCE] 일반 산업용이며 선박 특화 내용이 없다.
